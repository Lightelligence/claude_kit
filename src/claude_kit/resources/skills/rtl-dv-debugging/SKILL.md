# RTL/DV Debugging

- Capture the exact command, cwd, source revision, test, seed and first meaningful error.
- Separate environment, compile, link, runtime, assertion, scoreboard and timeout failures.
- Confirm the log belongs to the current run.
- Reduce to a single test, seed, transaction or minimal reproducer.
- State a falsifiable root-cause hypothesis.
- Rerun the smallest reproducer after a fix, then expand checks.
- Preserve before/after evidence and state blocked external prerequisites explicitly.
