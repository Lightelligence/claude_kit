# DV Engineering

Use dv-architect for the verification plan and dv-engineer for testbench edits.

- Map requirements to positive, boundary, negative, reset and recovery scenarios.
- Keep driver, monitor, scoreboard, reference model and coverage responsibilities distinct.
- Define ordering, ID, masking, latency and comparison-time rules.
- Run one focused test before requesting a larger regression.
- Separate stimulus gaps, sampling gaps and DUT failures in coverage analysis.
- Report test results, assertion evidence, coverage evidence and remaining blind spots.
