# Protocol and VIP

1. Confirm the exact protocol version and layer before applying rules.
2. Read the selected pack and the project's VIP mapping.
3. Keep VIP class names, library paths, macros, licenses and simulator settings project-local.
4. Check every instance has the intended clock, reset, direction and endpoint.
5. Run reset, one legal transfer, backpressure, error and recovery smoke.
6. Classify VIP warnings, protocol violations, scoreboard mismatches and environment failures separately.
